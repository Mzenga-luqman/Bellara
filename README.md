# Bellara System

Bellara System is a web-based business management platform designed to manage users, records, and workflows efficiently using a secure role-based system.

## Features
- User authentication
- Role-based access control
- Data management system
- Reporting tools
- Secure dashboard

## Tech Stack
- PHP / Laravel (or your actual stack)
- MySQL
- HTML, CSS, JavaScript

## Purpose
This system helps organizations digitize and manage operations efficiently from one centralized platform.
